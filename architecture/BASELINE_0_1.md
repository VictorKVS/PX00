# PX00 Architecture Baseline 0.1

Status: DRAFT

This baseline defines the contracts that must exist before PX00 runtime implementation begins.

## Required architecture decisions

- ADR-0001 — Global Core + Jurisdiction/Industry/Organization Profiles
- ADR-0002 — Integrated Management System Architecture
- ADR-0003 — Compliance/Knowledge Graph and Requirement-to-Evidence Traceability
- ADR-0004 — Governed Role Package Architecture
- ADR-0005 — Regulatory Knowledge Lifecycle and Regional Releases
- ADR-0006 — Universal Event, Traceability and Provenance Model

## Required contract families before code

- Constitution and authority model
- Project/product identity model
- Role package contract
- Protocol contract
- Knowledge/evidence/decision schemas
- Event/trace/provenance envelope
- Compliance applicability/conflict model
- Distribution and branding profile contract
- Evaluation and assurance model
- Retention/classification model
- MindForge adoption assessment

## Gate

Runtime implementation remains blocked until the baseline contracts have been reviewed and a deliberate PROCEED decision has been recorded.
